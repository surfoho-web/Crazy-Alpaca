# Crazy Alpaca GitHub Page

## GitHub Pages setup
1. Create a new **public** GitHub repository.
2. Upload `index.html` and `crazy-alpaca.apk` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.
7. Open the generated `https://YOUR-USERNAME.github.io/YOUR-REPO/` URL on Android.

The Download APK button points to `./crazy-alpaca.apk`, so it automatically downloads the APK from the same GitHub Pages site.
